# 功能与平台差异

基线：sxmqliveAndroid `c768cb12c`，2026-11-04；正式版本 `1.0.0` 已发布，Maven、Git Pod、SPM、HAR 和私有 OHPM 的精确版本消费已通过。宿主旧数据互读与真机行为仍须另验；渠道入口见 [README](../README.md)。

| 能力 | Android | iOS | OHOS | 共用边界 |
| --- | --- | --- | --- | --- |
| UTF-8 bytes 字符串 | AndroidMmkvStorage | GycMmkvStorage | NativeMmkvStorage | 保留 NUL、中文、emoji 与空字符串 |
| 旧字符串解码 | 非法 UTF-8 时回退 MMKV.decodeString | bytes 非法直接失败 | bytes 非法直接失败 | 沿用各端原行为，不擅自改写旧值 |
| 缺失/读取失败 | containsKey 校验 | contains(key:) 校验 | containsKey 校验 | Key 存在而 decode 失败必须失败 |
| 写/删/清空 | 返回真实 SDK 结果或验证删除 | 同左 | 同左 | 不把写失败伪装为成功 |
| removeAllExcept | 枚举并删除差集 | 同左 | 同左 | 保留值不经过 clear/重写 |
| 类型编解码 | TypedKeyValueStore | 同左 | 同左 | 缺失/非法数据/IO 失败区分；默认值不回写；取消继续抛出 |
| 原子 updateString | NativeKeyValueStore 实例锁 | 同左 | 同左 | 同一物理 Store 只装配一个实例，不承诺跨进程事务 |
| 应用存储 owner | host 注入 Context | host 注入 Documents/mmkv | host 注入 filesDir/mmkv 与 cacheDir | 不随页面关闭，不持有 Renderer |
| 原生桥 | Kotlin 直接 SDK | 宿主薄 Shared adapter | JSON + C++17 应用级 TSFN | 原生产品不嵌 Kotlin runtime、不引用 Shared/宿主导出符号 |

StoreID、业务 Key、账号切换、脱敏日志、迁移与保留白名单均由宿主持有。存储 SDK 线程安全不替代同实例读改写锁。

| 行为 | 回归入口 | 证据边界 |
| --- | --- | --- |
| 类型、失败、取消、并发读改写 | storage-core/src/commonTest | JVM/各 Native 执行结果逐目标记录 |
| Android 原格式与非法 UTF-8 回退 | storage-mmkv/src/androidUnitTest | Robolectric MMKV shadow；不证明设备 SDK 文件读写 |
| Swift 旧 bytes、失败、作用域和保留值 | verification/NativeStorageCompatibilityMain.swift | 替身可轻量执行；真实 MMKV 需单独 iOS 链接执行 |
| ArkTS 原格式、失败与保留值 | verification/native-mmkv-storage.test.cjs | TypeScript 转译 + MMKV 替身，不算 ArkTS/HAR 编译 |
| NAPI 主线程、12 路后台、异常后恢复 | verification/storage-native-bridge.test.cjs | Node 真实 NAPI 编译与线程调用，不算 OHOS 真机 |

Maven、Pod/SPM、HAR 的包管理、编译和设备证据独立。没有真机验收不意味着“不支持”；源码候选不能冒充已发布能力。
